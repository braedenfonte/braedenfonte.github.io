# Prep sheet layout (all courses)

This replaces section 3 ("Write the prep page") of every class-prep skill. Everything else in the
skill (finding the lesson, reading the material, publishing to the same artifact) stays the same.

Braeden is not an advanced student in every subject: write so he understands the idea, not just
recognizes the words. Plain words, short sentences, every term defined in one line the first time.
Aim for a 10-minute read. Put each section in its own clearly labeled card, and start each card
with one **bold takeaway line** so the page can be skimmed. No paragraph longer than 3 sentences.

## Sections, in this order

1. **Next class**: lesson number, title, date, Day 1/Day 2. If the lesson's own notes weren't posted
   yet, say so here in one line ("Built from the syllabus objectives; notes not posted yet").

2. **Main idea**
   - **In plain words**: what this lesson is about, in 2-3 sentences, like explaining it to a friend.
   - **Analogy**: one everyday comparison that makes it click (sports, Army life, money, a line at
     the DFAC, cooking...). Then one line: "Where the analogy breaks:".
   - **How it connects**: one line on how it builds on the last lesson, one on where it leads next.

3. **Key terms**: up to 6, each a one-line plain meaning. Tie terms back to the analogy when you can.

4. **How it works**
   - The method, formula or code pattern as short numbered steps.
   - A small diagram or table if it shows the idea better than words (inline SVG or HTML table).
   - One fully worked example, every step shown, each followed by a short "why".
   - Code courses (MA376 R, MA486 Python, EM481 ProModel): a short beginner-friendly snippet with a
     plain comment on each line.

5. **Practice**: 2-3 problems like the ones likely in class or on a quiz/WPR, easiest first.
   Each gets a one-line hint, and a full step-by-step solution in a collapsible "Show solution".

6. **Application**
   - One realistic scenario (Army, operations, sports, real data) showing where this is used and
     what decision it helps make.
   - **Common mistakes**: 2-3 bullets.
   - **Likely test question**: one line on how this would probably show up on a quiz or WPR.

7. **Before class**: short checklist (reading with chapter + pages, what to bring or finish).

8. **Due soon**: anything due at or before this class, with dates. "Nothing due" if none.

9. **Quick self-check**: 3 short questions, answers in a collapsible "Show answers".

10. **Sources**: links to the Canvas / website files used.

Never invent course facts (lesson titles, due dates, page numbers). Analogies, practice problems
and scenarios are yours to write, but they must match the lesson's actual content.
